# GLEDITECH — Web corporativa V4

Esta versión utiliza el logotipo original aportado por GLEDITECH, recortado **proporcionalmente a formato cuadrado** para que se muestre completo, sin deformación ni estiramiento diferencial. El tamaño de exportación es 1600×1600 píxeles con remuestreo de alta calidad. No es vectorial: la nitidez máxima continúa limitada por el archivo de origen.

Se actualizó la portada con una fotografía real, se reorganizó la galería, se conservaron los cuatro videos y los contactos oficiales, y se revisaron los estilos para escritorio y móvil.

## Publicar en GitHub + Render
1. Descomprimir y subir **todos los archivos** al repositorio de la web corporativa (no el sistema administrativo).
2. En Render crear o usar el servicio web conectado al repositorio, con `npm install` (Build) y `npm start` (Start).
3. Desplegar el último commit. No requiere base de datos ni variables `ADMIN_PASSWORD` / `DATABASE_URL`.
4. Recargar con Ctrl+F5.
